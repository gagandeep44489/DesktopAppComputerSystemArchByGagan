# Folder Structure

```text
src/app              composition root, providers, routing
src/config           theme and environment configuration
src/core             cross-cutting errors and HTTP concepts
src/domain           entities and repository abstractions
src/application      services and use-cases
src/infrastructure   API adapters and repository implementations
src/presentation     feature-first UI, pages, hooks, validation
src/shared           reusable shared primitives
src/assets           static assets
```
