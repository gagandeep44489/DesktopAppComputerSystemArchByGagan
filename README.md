# Cricket Coach Pro

A production-ready cricket coaching platform built with React 19, TypeScript, Vite, Material UI, React Router, React Hook Form, Zod, TanStack Query, and Axios-ready infrastructure.

## Highlights
- Clean Architecture with domain, application, infrastructure, and presentation layers.
- Feature-first pages for Home, Coach, Training, Booking, Gallery, Testimonials, Blog, FAQ, Contact, and 404.
- Dependency injection through a provider so UI depends on repository abstractions.
- Strict TypeScript, ESLint, Prettier, Husky, lint-staged, Commitlint, Vitest, and RTL.

## Commands
```bash
npm install
npm run dev
npm run build
npm run lint
npm run test
```
